# DEMO CONTROL ROOM

Локальная система управления проектами и задачами.

## 🎯 Идея

Создать единый центр управления для:
- Отслеживания прогресса по проектам (дерево навыков).
- Управления задачами (канбан-доска).
- Ведения журнала изменений и заметок.
- Хранения документации.

## 🛠 Реализация

- Статический веб-сайт на HTML5/CSS3.
- Визуализация дерева через Mermaid.js.
- Запуск встроенным Python HTTP-сервером (без внешних зависимостей).
- Данные хранятся в Markdown-файлах, редактируются вручную или через Git.
