# Demo Control Room

Локальная система управления проектами и задачами.

## Возможности

- **📊 Дашборд** — сводка по проектам на главной странице
- **🌳 Дерево развития** — визуальная карта проекта (Mermaid.js)
- **📋 Канбан-доска** — управление задачами по статусам
- **📝 Журнал** — логирование изменений и заметок
- **📚 Документация** — структурированное хранение информации

## Как работает

- Статический веб-сайт на HTML5/CSS3
- Визуализация дерева через библиотеку Mermaid.js
- Запуск встроенным Python HTTP-сервером (без внешних зависимостей)
- Данные хранятся в Markdown-файлах, легко редактируются и версионируются через Git

## Запуск

### Linux / macOS
./start-server.sh

### Любая ОС с Python
python3 -m http.server 8000

### Windows
python -m http.server 8000
start http://localhost:8000
