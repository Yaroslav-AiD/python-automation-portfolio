# Ozon Parser — сбор данных о товарах

Парсер товаров с маркетплейса Ozon через гибридный подход: **Selenium + встроенный JSON**.

## 🎯 Что делает
- Открывает страницу поиска Ozon через браузер (Selenium WebDriver).
- Позволяет пройти капчу вручную (один раз за сессию).
- Извлекает встроенный JSON с полными данными о товарах.
- Собирает: название, цену, старую цену, скидку, рейтинг, отзывы, ссылку, картинку.
- Сохраняет в Excel, убирая дубликаты.

## 🛠 Почему так сложно
Ozon использует многоуровневую защиту:
- Cloudflare (блокирует простые HTTP-запросы, ошибка 403).
- Обфускацию HTML (динамические классы и атрибуты).
- Капчу при подозрении на бота.

**Решение:** Selenium открывает настоящий браузер, что позволяет пройти капчу как человеку. После загрузки страницы скрипт извлекает **встроенный JSON** из атрибута `data-state` — это даёт 100% точные данные без парсинга вёрстки.

    Вернитесь в терминал и нажмите Enter.
