## Проекты

### 1. Kwork Scout — парсер заказов с фриланс-биржи

Скрипт открывает страницу проектов Kwork, находит заказы по ключевым словам (Python, парсинг, автоматизация, Selenium) и сохраняет результат в JSON-файл. Работает через Selenium WebDriver.

Стек: Python, Selenium, JSON

[Смотреть проект](./1_kwork_scout/)

---

### 2. Ozon Parser — сбор данных о товарах с маркетплейса

Гибридный парсер: Selenium открывает страницу как обычный браузер (с прохождением капчи вручную), а затем скрипт извлекает встроенный JSON с полными данными о товарах. Собирает название, цену, старую цену, скидку, рейтинг, количество отзывов, ссылку и картинку. Результат сохраняется в Excel, дубликаты убираются.

Почему гибрид: Ozon использует Cloudflare, обфускацию HTML и капчу. Простые HTTP-запросы блокируются (403). Selenium решает проблему с блокировкой, а парсинг JSON вместо HTML даёт 100% точные данные.

Стек: Python, Selenium, Pandas, Openpyxl, Requests

[Смотреть проект](./ozon_parser/)

---

### 3. Demo Control Room — система управления проектами

Локальный веб-инструмент для управления задачами и отслеживания прогресса. Включает дашборд, дерево развития проекта (визуализация через Mermaid.js), канбан-доску, журнал и раздел с документацией. Запускается встроенным Python-сервером, не требует установки дополнительных библиотек.

Стек: HTML5, CSS3, JavaScript, Python (http.server)

[Смотреть проект](./demo_control_room/)
